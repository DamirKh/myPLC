# myPLC — домашний терморегулятор на Xedge32

Прошивка: **Xedge32 4.4** на **ESP32-S3 (N16R8, 16 МБ flash, 8 МБ PSRAM)**.
Управление: твердотельное реле насоса тёплого пола. Датчики: DS18B20 на трёх
шинах 1-Wire.

Текущий статус:

- плата определена и прошита Xedge32 4.4 (ESP32-S3, 16 МБ flash, 8 МБ PSRAM);
- зафиксированы решения по архитектуре, логике, доступу и безопасности;
- создан скелет Xedge32-приложения с модулями, тестами и минимальным веб-интерфейсом;
- добавлена индикация режимов на встроенном RGB-светодиоде (WS2812B, GPIO48 — проверено на плате);
- модульные тесты проходят;
- приложение ещё не загружено на плату;
- реальные датчики, SSR и насос ещё не подключены и не проверены.

Приложение пока не включено в автозапуск (`.config`: `autostart = false`).

## Первый вход

После установки приложения откройте `http://<IP>/setup.lsp` с доверенной LAN и
задайте 4-значный PIN. PIN вводится экранной клавиатурой с круглыми клавишами.
Настройки и датчики находятся в `/admin/`; обзор и уставка остаются публичными.

## Интерфейс

- На узком экране (телефон) автоматически включается компактный вид: только
  температура помещения, пола, уставка и статус насоса.
- Переключатель **Компактный/Полный вид** запоминается в `localStorage` на
  конкретном устройстве.
- В компактном виде уставка открывается нажатием на плитку «Уставка»: снизу
  появляется панель с кнопками −/+, закрытием и сбросом override. Через минуту
  бездействия панель закрывается автоматически.
- Подача/обратка, датчики и диагностика в компактном режиме скрыты под
  «Подробнее».
- На главной — ЖК-часы `ЧЧ:ММ` с мигающим двоеточием; время считается по
  настроенному смещению UTC.
- В `/admin/settings.lsp` настраиваются нижняя и верхняя границы уставки
  воздуха; базовая уставка должна входить в этот диапазон.
- Светлая и тёмная темы: переключатель в шапке, выбор запоминается в
  `localStorage`; без сохранённого выбора используется тема системы.
- ЖК-часы следуют теме: светлый корпус с тёмными сегментами или тёмный корпус
  с зелёными сегментами.
- В шапке показывается состояние MQTT: зелёная иконка — подключено, красная —
  включено, но нет связи. Если MQTT выключен, иконка скрыта.
- Адрес MQTT-брокера проверяется при сохранении; невалидный host отклоняется
  и не запускает попытки подключения.
- Все CSS, JS и SVG-иконки локальные: приложение работает без интернета.

## Быстрый старт

Тесты (нужен Lua 5.4):

```bash
make test
```

Сборка ZIP для загрузки в Xedge32:

```bash
make package
# результат: build/thermostat.zip
```

Локальный MQTT-брокер для тестов (нужен Docker):

```bash
make mqtt-up      # Mosquitto на 0.0.0.0:1883
make mqtt-test    # проверка publish/subscribe
make mqtt-watch   # слушать home/floor/thermostat/#
make mqtt-down    # остановить
```

Брокер тестовый, без авторизации и TLS. Указывайте в настройках приложения
LAN-IP компьютера с Docker, порт `1883`. Не публикуйте порт в интернет.
Подробнее — в [docs/deployment.md](docs/deployment.md).

Загрузка: подключиться к AP `xedge32` (пароль по умолчанию `12345678`) или к
сети платы, открыть `http://xedge32.local/rtl/`, загрузить ZIP через
**Firmware Update & App Upload**, затем включить приложение и `Autostart`.

## Важно

Проект управляет насосом 230 В AC. До подключения насоса необходимо проверить
SSR, автоматический выключатель, изоляцию и независимый термостат перегрева.
Подробности — в [docs/hardware.md](docs/hardware.md).
