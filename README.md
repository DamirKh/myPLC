# myPLC — домашний терморегулятор на Xedge32

Прошивка: **Xedge32 4.4** на **ESP32-S3 (N16R8, 16 МБ flash, 8 МБ PSRAM)**.
Управление: твердотельное реле насоса тёплого пола. Датчики: DS18B20 на трёх
шинах 1-Wire.

## Текущий статус

- Приложение установлено, запущено, `Auto Start` включён.
- Публичные обзор и уставка работают; настройки защищены PIN (`/admin/`).
- Реальные датчики, SSR и насос ещё не подключены и не проверены.
- Приложение работает полностью локально, без интернета.

## Быстрый старт

```bash
make test       # модульные тесты (Lua 5.4)
make package    # build/thermostat.zip для Xedge32
```

Загрузка приложения — через **Firmware Update & App Upload** в Xedge32.
Подробности — [docs/deployment.md](docs/deployment.md).

Локальный MQTT-тест (Docker): `make mqtt-up` / `make mqtt-test` / `make mqtt-watch`.
Подробности — [docs/deployment.md](docs/deployment.md).

Проект управляет насосом 230 В AC. Перед подключением насоса обязательно
проверить SSR, автоматический выключатель, изоляцию и независимый термостат
